Large-input bookmarklet

Fills the first form's text fields with 1,000,000 characters and submits it.

⤺ Fill form with 1 MB
How to install
  1. Make sure your bookmarks bar is visible (Chrome/Edge: Ctrl+Shift+B / Cmd+Shift+B; Safari: View → Show Favorites Bar).
  2. Drag the blue button above onto the bookmarks bar and drop it.
  3. Open the page with the form you want to test, then click the bookmark.
  4. Open the dev console (Cmd+Option+J / Ctrl+Shift+J) to see filled N fields, 1000000 chars.

If dragging doesn't work, right-click the button → "Copy link address", create a new bookmark, and paste the copied link as the URL.
